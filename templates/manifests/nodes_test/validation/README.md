# nodes_test Validation Pack

This pack proves every Phase 0 SDK node type runs end-to-end and produces
the expected outputs.

## What it proves

- `csv_reader` reads `fixtures/sample.csv` and emits `sample.parquet`.
- `generic_file` copies the fixture via the `file://` scheme to
  `sample_copy.csv`.
- `sql` bootstraps a target schema and creates the round-trip table.
- `db_writer` loads `fixtures/sample.parquet` into the table in
  `truncate` mode.
- `db_reader` round-trips the rows back into `extracted.parquet`.
- `py2table` builds a Polars DataFrame and persists it as
  `doubled.parquet`.
- `python` runs a glue transform that returns a status dict.
- `r` shells out to Rscript and writes `r_summary.txt`.

## What it does NOT prove

- That production-scale data passes through the nodes correctly.
- That every parameter variant of every node works — only the canonical
  happy path for each node type is exercised.
- That `emits_cdm: true` templates behave correctly — `nodes_test` is a
  diagnostic, not an ingestion template.

## How to run

The pack runs automatically as part of the `nodes_test` E2E test in CI
(see `templates/tests/e2e/test_nodes_test.py`). To run manually against
a testcontainers-managed Postgres:

```bash
cd /home/smudoshi/Github/Parthenon/templates
uv run pytest tests/e2e/test_nodes_test.py -v
```

## Pack layout

| File | Purpose |
|---|---|
| `inputs/parameters.json` | Parameter template for the run (the test substitutes `fixtures_dir` with an absolute path at runtime). |
| `expected/post_conditions.yaml` | Artifact, row-count, and column-value assertions checked after the run. |
| `dqd_checks.yaml` | Empty list — `nodes_test` produces no CDM data. |
| `README.md` | This file. |

## Fixtures

| File | Purpose |
|---|---|
| `fixtures/sample.csv` | Canonical 5-row CSV consumed by `csv_reader` and `generic_file`. |
| `fixtures/sample.parquet` | Generated by `build_fixtures.py`; loaded by `db_writer`. |
| `fixtures/build_fixtures.py` | Idempotent generator. Re-run on fixture changes. |
