# Verifying the Source Installer

Current Parthenon Community releases are source-only. The supported public path downloads `install.sh`, fetches a tagged GitHub source tree from `Acumenus-Data-Sciences/Parthenon`, and runs the in-repo Python installer.

Native installer signatures, Tauri updater manifests, Linux package signatures, and binary SLSA attestations do not apply to the current public Community release because native artifacts are paused. This page documents what you can verify today.

## What ships today

| Item | What it is | How to verify |
|---|---|---|
| `https://parthenon.acumenus.net/install.sh` | Public bootstrap script | Compare it to the repo copy and review it before running |
| GitHub release source archive | Tagged source tree used by the bootstrap | Pin `--version`, inspect the tag, and record the archive checksum you used |
| Docker images | Runtime containers pulled during install | Review Compose files and pin image digests where your environment requires it |

GitHub also provides automatic source archives for every tag. Those archives do not have Parthenon-published `.sha256` or `.asc` sidecars today, so compute and retain your own checksum for change-control records.

## Verify the public bootstrap script

Download the live script and the repository copy:

```bash
curl -fsSLo parthenon-install-live.sh https://parthenon.acumenus.net/install.sh
curl -fsSLo parthenon-install-repo.sh \
  https://raw.githubusercontent.com/Acumenus-Data-Sciences/Parthenon/main/frontend/public/install.sh
```

Compare them:

```bash
cmp parthenon-install-live.sh parthenon-install-repo.sh
```

No output means the files match. Then record a local checksum:

```bash
shasum -a 256 parthenon-install-live.sh
```

Read the script before running it in a regulated environment:

```bash
less parthenon-install-live.sh
```

You should see `REPO="Acumenus-Data-Sciences/Parthenon"` and source archive URLs under `https://github.com/Acumenus-Data-Sciences/Parthenon/archive/refs/tags/`.

## Pin and verify a release tag

Use a pinned tag for repeatable installs:

```bash
curl -fsSL https://parthenon.acumenus.net/install.sh | sh -s -- --version v1.0.7
```

Before running, confirm the tag exists and record the resolved commit:

```bash
git ls-remote --tags https://github.com/Acumenus-Data-Sciences/Parthenon.git refs/tags/v1.0.7
```

If your policy requires reviewing the archive first, download it directly:

```bash
curl -fL -o parthenon-v1.0.7.tar.gz \
  https://github.com/Acumenus-Data-Sciences/Parthenon/archive/refs/tags/v1.0.7.tar.gz

shasum -a 256 parthenon-v1.0.7.tar.gz
tar -tzf parthenon-v1.0.7.tar.gz | head
```

Store the checksum and the `git ls-remote` output with your deployment record.

## Verify an installed source checkout

After the bootstrap completes:

```bash
cd ~/Parthenon
cat .parthenon-source-ref
git remote -v 2>/dev/null || true
git status --short 2>/dev/null || true
```

`.parthenon-source-ref` records the release tag or source ref selected by the bootstrap. If the install came from a Git clone, `git status --short` should be clean before you start making local changes.

## Binary and updater verification

The native GUI track is paused. If native packages return, the release must publish updated verification instructions for:

- macOS code signing and notarization
- Windows Authenticode or Trusted Signing
- Linux package signatures and checksums
- Tauri `latest.json` updater signatures
- Build provenance attestations

Until then, do not rely on older `.dmg`, `.msi`, `.deb`, `.rpm`, `.AppImage`, `.sha256`, `.asc`, or `latest.json` instructions for current Community installs.

## What to do if verification fails

1. Do not run the installer.
2. Re-download from `https://parthenon.acumenus.net/install.sh`.
3. Compare against the repository copy under `frontend/public/install.sh`.
4. If the mismatch persists, file a security advisory at `https://github.com/Acumenus-Data-Sciences/Parthenon/security/advisories`.

A failure most likely means the local copy is stale, incomplete, or modified in transit. Treat it as a supply-chain finding until the source is understood.
