# Test Skip Inventory (2026-06-21)

Closes the Phase 0 completion-plan item "Capture a skip inventory by module and
classify each skip." Each skipped test cluster below is classified and assigned a
disposition owner. Generated by sweeping `markTestSkipped`/`->skip` (Pest),
`it.skip`/`test.skip` (Vitest/Playwright), and `pytest.skip`/`importorskip`
(pytest) and reading the skip reason strings.

**Classifications:** `env-required` (needs a sidecar, data, or infra not present
locally — belongs in a hosted smoke gate), `tooling-limited` (a test-runner
limitation, e.g. jsdom), `intentional` (a deliberate conditional or scope), and
`bug-masking` (hides a real defect — must be resolved).
