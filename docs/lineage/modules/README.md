# Module Lineage

This directory records how feature areas evolved: shipped work, acceptance
notes, closeouts, runbooks, and module-specific audits.

Keep durable module history here. Put implementation plans in
`docs/lineage/plans/`, formal design specs in `docs/lineage/design/specs/`, and
cross-cutting operational procedures in `docs/lineage/operations/`.
