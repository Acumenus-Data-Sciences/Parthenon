# OMOP Common Data Model

The **OMOP Common Data Model (CDM)** is a standardized way to organize observational healthcare data so the same analytic methods can be applied consistently across different databases.

It defines a shared relational schema, common conventions, and standardized vocabularies so researchers can compare results across sites and run reproducible studies without redesigning the data model each time.
